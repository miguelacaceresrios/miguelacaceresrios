<h1>Proyectos destacados</h1>

<h3>Champion Sport Events</h3>

Plataforma de eventos deportivos en producción, con dominio propio: publica eventos, inscribe atletas y cobra en línea.

- La inscripción pasa de `pendiente` a `pagada` solo cuando el webhook de Stripe lo confirma.
- Los montos se guardan en centavos para evitar errores de redondeo.
- Acceso separado por roles y permisos.
- HTTP nativo de Node, sin framework de servidor.

`Node.js` `SQLite` `Stripe Checkout` `HTML/CSS/JS`

<br>

<h3>Apus</h3>

Herramienta para quien trabaja con muchos repositorios a la vez. Núcleo en Go y extensión de VS Code en TypeScript, en un solo monorepo.

- Encadena `add`, `commit` y `push` en un solo paso, en modo manual o automático.
- Muestra qué se ejecuta en cada etapa.
- **apus-guard** (en desarrollo): escanea secretos con reglas para .NET, Azure y SQL Server, bloquea el push ante hallazgos críticos y nunca imprime el valor detectado.
